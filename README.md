# Python OOP Activities

This repository contains Python programs created as part of my Object-Oriented Programming activities.

## Activities

### Activity 1
- `Assin1_c1.py`
- `Assin1_c2.py`
- `Assin1_c3.py`

Demonstrates basic Object-Oriented Programming concepts using classes and objects, including a simple library-related implementation.

### Activity 2
- `Assin2.py`

Demonstrates a payment processing system using different payment methods such as Credit Card, Debit Card, UPI, and Net Banking.

### Activity 3
- `Assin3.py`

Demonstrates Python OOP concepts including decorators, class methods, and magic methods.
